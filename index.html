Why do the hashes differ?
SHA-256 is a cryptographic hash function with the avalanche effect: even a single-bit change in the input produces a dramatically different hash output. This property makes it suitable for detecting file modifications in digital forensics.

Note: The original content was never overwritten. A separate modified copy was created and compared against the original's baseline hash.
