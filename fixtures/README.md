# Fixtures Directory

This directory contains **controlled synthetic test files** generated by
`test_fixtures.py` for the ForensiCheck validation suite.

## Contents

| File               | Description                                    |
|--------------------|------------------------------------------------|
| normal_text.txt    | Simple ASCII sentence                          |
| binary_data.bin    | Every byte value 0x00–0xFF                     |
| empty_file.txt     | Zero-byte file                                 |
| unicode_text.txt   | Latin-extended, CJK, and emoji characters      |
| large_file.txt     | ~100 KiB repeated-line file for chunked reading|
| modified_text.txt  | Single-character alteration of normal_text.txt |

These files are **generated automatically** — do not edit them manually.
Their expected SHA-256 hashes are recorded in `test_fixtures.py`.
